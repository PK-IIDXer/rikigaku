# 主張
2つの[[質点]]$\mathbf{r}_1,\mathbf{r}_2:I\to\mathbb{R}^3$があるとき
- [[質点]]$\mathbf{r}_1$が[[質点]]$\mathbf{r}_2$から受ける[[運動方程式#真の力|真の力]]を$F_{12}(t,\mathbf{r}_1(t),\mathbf{r}_2(t),\dot{\mathbf{r}}_1(t),\dot{\mathbf{r}}_2(t))$
- [[質点]]$\mathbf{r}_2$が[[質点]]$\mathbf{r}_1$から受ける[[運動方程式#真の力|真の力]]を$F_{21}(t,\mathbf{r}_2(t),\mathbf{r}_1(t),\dot{\mathbf{r}}_2(t),\dot{\mathbf{r}}_1(t))$
とおくとき、$$F_{12}(t,\mathbf{r}_1(t),\mathbf{r}_2(t),\dot{\mathbf{r}}_1(t),\dot{\mathbf{r}}_2(t))=-F_{21}(t,\mathbf{r}_2(t),\mathbf{r}_1(t),\dot{\mathbf{r}}_2(t),\dot{\mathbf{r}}_1(t))$$をみたす。
# 説明
一般的に「壁を押したとき、自分は壁を押してるけど、壁も自分を押してくる(から、壁も自分も静止する)」と説明されるもので、その認識で間違いはないです。ただし、僕たちは[[力]]についてよく考え、[[慣性系]]と[[慣性の法則]]を切り離し、[[ガリレイの相対性原理]]を至上原理として考えたので…まあ主張がいろいろめんどくさくなりました。数式で書くと大変ですね。

作用反作用の法則はほかの法則と違って、二つの[[質点]]が登場します。[[力]]はベクトルであるというのが、僕たちの非常にざっくりとした結論なのですが、作用反作用の法則は「二つの[[質点]]だけが[[慣性系]]にあるとき、[[力]]は自身ともう一つの[[質点]]にしか依存しない」と言っていて、しかも「それらの絶対値は等しく」、「向きは互いに逆である」とも言っています。このことは、ニュートンがケプラーの法則から万有引力を導くための最後の一手なのです！
# [[ガリレイの相対性原理]]をみたすことの確認
これはほぼ自明で、[[運動方程式#真の力|真の力]]の定義によりガリレイ変換によってそれぞれの力は$$F'_{ij}=RF_{ij}$$と変換されるのでした($R$はガリレイ変換に現れる[[回転行列]])。したがって等式は、ガリレイ変換前とガリレイ変換後でその姿を変えません。
