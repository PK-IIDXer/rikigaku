# 定義
[[絶対慣性系]]と[[ガリレイ変換]]で互いに移りあう[[座標系]]を慣性系という
# 説明
慣性系という言葉をうまく定義するのは実は難しい。「慣性の法則が成り立つ座標系」と言ってしまうと、「慣性の法則とは、慣性系において自由粒子は等速直線運動する」という説明になってしまうので、循環論法である。

これを物理的には意味が通じるから十分ではあるが、数学的には気になるところなので、上記のような工夫を施した。まず座標系というのは、多様体論を知っている人に向けて言えば、時空という位相空間に対する一つのグローバルなチャートである。時空というのはそもそも$\mathbb{R}\times\mathbb{R}^3=\mathbb{R}^4$で定義したのだから、恒等写像は一つのチャートを定める。これを絶対慣性系と呼んだわけである。またガリレイ変換は古典力学における一つの座標変換（つまり微分同相）として要請せらるものであるから、数学的には上記のように定義するのが妥当であろう。
