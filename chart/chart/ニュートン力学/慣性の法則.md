# 主張
ある[[慣性系]]が存在して、任意の[[自由粒子]]は[[等速直線運動]]を行う
# 説明
ほかのページで何度も説明しているように、[[慣性系]]と慣性の法則の循環参照を解決するために心血を注いだ主張となっています。[[慣性系]]の定義は、[[絶対慣性系]]の存在を先に仮定し、それと独立して[[ガリレイ変換]]を定義することで、慣性の法則と切り離しました。また[[自由粒子]]は、先に[[力]]というものを個別に定義して、合力0の力がかかっている質点として定義したのでした。これも[[等速直線運動]]とは切り離されています。結果としてこの法則は、[[ガリレイの相対性原理]]が満たされるかどうかというのが非自明になってしまいました。これはすぐ証明します。

それよりも主張の構造を見てわかる通り、これは「ある条件を満たす[[慣性系]]の存在公理」です。そしてその条件というのが「任意の[[自由粒子]]は[[等速直線運動]]を行う」というものなので、それぞれの定義を思い出せば「合力0の[[質点]]の二階微分は消える」というような条件を満たす[[慣性系]]が存在するといっています。古典力学の土台となる「[[慣性系]]」においては、従って3階以降の微分は本質的にはあまり考える必要がないことを意味しています。2階微分までが基本法則になるべきである。慣性の法則はそういうことを宣言しているのです。
# [[ガリレイの相対性原理]]を満たすことの確認
[[質点]]の運動に関してガリレイ変換をすると$$
  \mathbf{r}'(t'):=\begin{pmatrix}
    t'\\
    r'_x(t')\\
    r'_y(t')\\
    r'_z(t')
  \end{pmatrix}
  =
  \begin{pmatrix}
    t+t_0\\
    v_1t+R_{11}r_x(t)+R_{12}r_y(t)+R_{13}r_z(t)+x_0\\
    v_2t+R_{21}r_x(t)+R_{22}r_y(t)+R_{23}r_z(t)+y_0\\
    v_3t+R_{31}r_x(t)+R_{32}r_y(t)+R_{33}r_z(t)+z_0
  \end{pmatrix}
$$となる。これの1回[[微分]]は$$
\begin{align*}
  \frac{d\mathbf{r}'(t')}{dt'}&=\frac{dt}{dt'}\frac{d\mathbf{r}'(t')}{dt}=\frac{d(t'-t_0)}{dt'}\frac{d\mathbf{r}'(t')}{dt}=\frac{d\mathbf{r}'(t')}{dt}\\
  &=\frac{d}{dt}
  \begin{pmatrix}
    v_1t+R_{11}r_x(t)+R_{12}r_y(t)+R_{13}r_z(t)+x_0\\
    v_2t+R_{21}r_x(t)+R_{22}r_y(t)+R_{23}r_z(t)+y_0\\
    v_3t+R_{31}r_x(t)+R_{32}r_y(t)+R_{33}r_z(t)+z_0
  \end{pmatrix}\\
  &=
  \begin{pmatrix}
    v_1+R_{11}\dot{r}_x(t)+R_{12}\dot{r}_y(t)+R_{13}\dot{r}_z(t)\\
    v_2+R_{21}\dot{r}_x(t)+R_{22}\dot{r}_y(t)+R_{23}\dot{r}_z(t)\\
    v_3+R_{31}\dot{r}_x(t)+R_{32}\dot{r}_y(t)+R_{33}\dot{r}_z(t)
  \end{pmatrix}
\end{align*}
$$となり、もう一度[[微分]]すると$$\begin{align*}
  \frac{d^2\mathbf{r}'(t')}{dt'^2}&=\frac{d}{dt}
  \begin{pmatrix}
    v_1+R_{11}\dot{r}_x(t)+R_{12}\dot{r}_y(t)+R_{13}\dot{r}_z(t)\\
    v_2+R_{21}\dot{r}_x(t)+R_{22}\dot{r}_y(t)+R_{23}\dot{r}_z(t)\\
    v_3+R_{31}\dot{r}_x(t)+R_{32}\dot{r}_y(t)+R_{33}\dot{r}_z(t)
  \end{pmatrix}
  =
  \begin{pmatrix}
    R_{11}\ddot{r}_x(t)+R_{12}\ddot{r}_y(t)+R_{13}\ddot{r}_z(t)\\
    R_{21}\ddot{r}_x(t)+R_{22}\ddot{r}_y(t)+R_{23}\ddot{r}_z(t)\\
    R_{31}\ddot{r}_x(t)+R_{32}\ddot{r}_y(t)+R_{33}\ddot{r}_z(t)
  \end{pmatrix}\\
  &=R\frac{d^2\mathbf{r}(t)}{dt^2}
\end{align*}
$$を満たすので、「質点の二階微分が消える」という慣性の法則の結果はガリレイ変換で保たれており、慣性の法則は[[ガリレイの相対性原理]]を満たしています。

結果的に、任意の慣性系において自由粒子という概念がうまく定義されており、しかもそれは等速直線運動を行うことがわかりました。
