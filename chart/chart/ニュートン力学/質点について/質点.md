# 定義
$I:=[a,b]\subset\mathbb{R}$を閉区間、$m>0$とする。このとき、[[連続写像]]$\mathbf{r}:I\to\mathbb{R}^3$と正の実数$m$の組を、閉区間$I$における **(慣性)質量** $m$の **質点** あるいは **質点の運動** という。写像$\mathbf{r}$の定義域の一点$t$は **時刻** と呼ばれる。

質点の運動が明らかに2次元平面や1次元の直線に制限される場合、あるいはそのようなモデルを採用する場合、最初から$\mathbf{r}$の値域を$\mathbb{R}^2$あるいは$\mathbb{R}$に取っておくことがある。

# 説明
地球から夜空を見上げた時、そこに浮かぶ星々はほとんど点に見える。これらは時刻$t$に依存して「連続的に」運行しているように見える。まずはその理論を組み立てる出発点として、上記の質点の定義は必要であった。

一方で身近な物体には大きさがあり、ひいき目に見ても「点」には見えない。しかし塔から落とされたボールの軌道を調べたり、木から落ちるリンゴの運動を調べるという理想的な状況を考えたとき、これらの研究対象は「点」であるとみなして差し支えない(重心を考えるとかすればよい)。もし点であるとみなして問題が起こったら、その時にまた専用の理論を組み立てればよい。実際、剛体の理論とか破壊力学とか、そういった分野が確立していて、人間文明の土台を支えている。ともあれ「ボールを点とみなす」、「摩擦を無視する」、「空気抵抗を無視する」といった理想化された問題設定に違和感を覚える人は多いだろうが、理論を組み立てるという大仕事をするときは、まずは自分の理想を動かしてみるべきなのである。

古典力学の理想はというと、もともとニュートンは、天体の運行を身近な運動現象とひとまとめにした理論を構築しようとしていたようである。そしてこの理想化はケプラーの法則の理論的再現をもって、当時は「神の領域」であった天体の運行と、「人間の領域」であったリンゴの運動が、実際には全く同じ法則によって縛られているということが証明された。質点の定義は、まさにその初手なのである。

「ニュートンはリンゴが木から落ちるのをみて万有引力を思いついた」という話があるが、あれは多分嘘である。もしかすると誰かが、惑星が太陽を回る法則が人間界の法則と全く同じであることを説明するための一例として、「リンゴが木から落ちるのと、火星の運行は全く同じ法則で動いている」などと説明したかもしれない。それがいつの間にかニュートンが言ったことになってしまって、最後には因果が逆になって伝わっているだけかもしれない。これは僕の想像にすぎないのだが、実際にそういうことはよくあるのである。アインシュタインとかシュレーディンガーとかにもそういう逸話は…もはや枚挙にいとまがない。
